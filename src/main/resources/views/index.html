EUDI Wallet Simulator

Web-based wallet simulator for testing OID4VP verifiers. A verifier sends the browser here via its wallet link (/authorize?client_id=…&request_uri=…). Trust lists are served at /trust-lists/credentials and /trust-lists/wallet-providers, the status list at /status-list, revocation via POST /api/credentials/{id}/status. Verifiers need a registration certificate from /api/registration-certificates?client_id=… for their verifier_info.
